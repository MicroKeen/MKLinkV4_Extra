## 拆分前的触发情境记录（当前仅前三种情境生效）

| 中文情境 | 对应ID | 触发条件 |
|---|---|---|
| 空手进店 | `greeting_empty` | 进店时没有可出售的鱼获。 |
| 带普通鱼进店 | `greeting_fish` | 携带普通鱼获，没有优先触发稀有鱼或大鱼对白。 |
| 带船尾大鱼进店 | `greeting_giant` | 船尾挂着大鱼，且没有触发稀有鱼或日常线索。 |
| 出售成功 | `sold` | 成功出售鱼获。 |
| 购买成功 | `bought` | 成功购买装备、饵料或容器。 |
| 金币不足 | `poor` | 购买时钱不够。 |
| 没有鱼可卖 | `empty` | 点击出售，但没有可出售鱼获。 |
| 已经拥有 | `owned` | 购买已经拥有的装备，或已拥有同级/更高级容器。 |
| 无法继续购买 | `full` | 饵料库存达到上限等，无法继续容纳商品。 |
| 黄化土鲶 | `rare_catfish` | 携带亮黄色、白色配色的黄化土鲶进店。 |
| 长鳍马口 | `rare_hooksnout` | 携带长鳍马口进店。 |
| 红色长尾鲤 | `rare_carp` | 携带红色长尾鲤进店。 |
| 白化鳖 | `rare_softshell` | 携带白化鳖进店。 |
| 日常稀有鱼线索 | `rare_hint` | 没有稀有鱼优先对白时，每次进店有5%概率触发。 |

携带多种稀有鱼时，优先选择携带总价值最高的一种；稀有鱼对白优先于日常线索和普通招呼。购买、出售等交互完成后的反馈优先显示对应结果。
