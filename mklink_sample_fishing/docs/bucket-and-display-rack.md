# 储鱼容器与商店列表（当前v18）

小木桶10kg，大木桶20kg/300coins，储鱼箱35kg/750coins。扩容保留鱼获，可容纳时收入船尾大鱼。背景压暗，文字独立底板。

鱼库只显示当前存有鱼的鱼种，按稳定鱼种顺序紧凑排列。船尾有鱼时追加最后一页；空库统一提示，不再保留十二个空页。容量、每页数量/重量/售价、合计价值以及当前金币余额分别显示。

商店左侧五行滚动列表，16个商品/服务ID保持不变；列表显示名称与选中高亮，详情左下角显示28像素装备图标，文字右移并用三行显示名称/售价、描述、实际效果。背景重绘为粗像素正面墙、壁灯与挂具，窄柜台前沿位于人物手臂下方。移除原独立商品摆拍位图。列表坐标见 `data/shop_layout.json`，可用 `tools/prepare_shop_layout.py` 导出。
