## 下饵水深和分布

背包可选择表层、0.5、1、2、3、4.5、6米或到底；默认到底。有限深度超过落钩点水深时截到当地底面。选择“到底”总是使用当地底深，不能理解为全地图统一6米。

层判定按实际下饵深度进行：距离底面不超过max(20cm,当地水深/8)为底层，其余距离水面不超过30cm为表层，其余达到当地水深60%为下层，否则中层。浅水中表层和底层可能很接近，本版优先判为底层。米数为虚拟游戏单位；地图像素与真实米数没有比例换算。

| 物种 | 生效钓层 | 近岸限制 | 下饵深度范围/cm |
|---|---|---|---:|
| 鲫鱼 | 中/下/底 | 无硬限制，偏芦苇湾 | 0–650 |
| 鲤鱼 | 中/下/底 | 无硬限制，偏开阔水面 | 0–650 |
| 马口 | 表/中 | 偏缓流入口 | 0–300 |
| 土鲶 | **底层** | 偏泥底深槽 | 80–650 |
| 子陵吻虾虎鱼（趴地虎） | 底层 | **仅近岸** | 5–250 |
| 黑鱼 | 表/中/下 | 偏芦苇湾 | 0–450 |
| 黄颡鱼 | 底层 | 偏芦苇湾/泥底沟 | 15–650 |
| 餐条 | 表/中 | 偏开阔水面 | 0–300 |
| 斑鳜 | 中/下/底 | 偏缓流/砾石区 | 30–650 |
| 中华鳖 | 底层 | 偏泥底深槽 | 15–650 |
| 溪蟹 | 底层 | **仅近岸** | 15–200 |

近岸指落钩点距离任一水边≤120世界像素，不是船的位置。所有“偏好”用分区系数改变权重；粗体限制是排除条件。分布字段`game_distribution`独立于研究资料`habitat.numeric_depth_m=null`，不把资料中没有验证的自然深度当实测值。

```text
有效权重 = 基础物种权重 × 地区系数 × 所选饵料系数
不满足水域、层、近岸或深度条件 → 权重0
```

先筛选后抽取种类，再按原尺寸分布生成体型。饵料不能突破硬限制；没有任何符合条件的鱼时不会回退到全地图抽鱼，等待中会显示暂时没鱼。当前正常默认配置大多数位置仍有符合条件的物种。

铜/银/金70/25/5保留为基础权重比例，局部实际比例会随位置、钓深、饵料改变；卡面金属色和体型星级保持。没有水下鱼种图标，渔获身份仍在收鱼成功后揭晓。

## 背包和装备

空闲划船/上岸时短按左键或空格打开背包。大格子展示完整鱼竿位图，旁边四格是线钩组合、浮漂、鱼饵、钓深；底部为码头、图鉴、返回。暖纸底、黄铜细框，深棕角标表示选中，赭红角标及亮黄沿表示正在调整；名称与属性集中显示在下方详情栏。A/D或拨轮旋转选择格子，点按进入调整，再旋转选装备，点按确认；选择返回恢复原来的船上/岸上状态。

图示来自16个原创ImageGen装备对象，以Arm-2D masked copy/transform绘制；边框和连接线使用公共图元。名称宽度按实际字形度量检查，装备名称度量每帧一次、PFB复用。默认装备玻纤竿、通用线钩、红白漂、蚯蚓、到底。该原型所有选项均可选，尚未引入购买、库存数量、饵料消耗或存档。素材及详细布局见[backpack-rpg-design.md](backpack-rpg-design.md)。

| 鱼竿 | 满蓄力抛距/px | 收线效率 |
|---|---:|---:|
| 竹竿 | 88 | 90% |
| 玻纤竿 | 116 | 100% |
| 碳素竿 | 140 | 110% |

抛距越长，蓄力后段镜头会逐步向抛竿方向移动，使落点保持在240像素窗口内；松手时镜头连续。岸上的船保留船体，人物独立站在码头，避免船上和岸上同时出现主角。

| 线钩组合 | 强度 | 可控距离单位 | 提竿窗口系数 |
|---|---:|---:|---:|
| 细线小钩 | 75 | 14,000 | 110% |
| 通用线钩 | 100 | 18,000 | 100% |
| 强韧大钩 | 140 | 26,000 | 90% |

鱼钩是线组的数据成员，不提供独立换钩入口。强度影响张力危险阈值，可控距离影响逃远阈值，提竿窗口系数体现配套钩的游戏差异。鱼竿效率影响每格收线进度；重量与鱼种仍决定拉力。搏鱼中不打开背包，防止即时换装备绕过危险。

浮漂有红白、鹅毛、夜光三种，改变颜色和形状，当前不改提竿窗口或漂相规则。饵料为蚯蚓、米饭、面饵、小鱼、虾饵；逐物种系数在[data/equipment.json](../data/equipment.json)，是游戏设定。

## 实现、复测与移植

地图、分布和装备导出为只读紧凑C表；运行时无JSON解析和每鱼对象、无新增堆分配。深度插值、11项加权筛选仅在必要查询/抛竿时执行；临时权重数组22B位于栈。地形条和背包按PFB有效区域跳过无关块。

地图/装备逻辑使游戏状态由164B增加为180B，PC静态段增加32B。随后RPG行囊改造复用既有缓存和transform，未再增加静态RAM：派生场景680B，含游戏状态、字形度量缓存和200B transform。PFB仍11,520B，当前位图载荷492,528B，其中装备23,808B；没有新增整屏缓冲。PC静态RAM246,040B，扣除PC显示缓冲230,400B后为15,640B。目标MCU布局、栈/堆和帧率仍需目标工具链实测。类ROM和字体数据见[memory-report.md](memory-report.md)。

```powershell
python tools/prepare_map.py
python tools/prepare_remarks.py
.\build.ps1
python tools/verify_species_assets.py
python tools/prepare_previews.py
python tools/memory_report.py
```

修改物种尺寸/行为参数时还需`prepare_species.py --data-only`；修改星级分布需重新标定。正常构建使用已经保存的生成C文件，不需要安装Python。

15项CTest通过，包括84,000次局部分布抽取、11种可达性、近岸/底层硬排除、空集合不消耗随机数、饵料权重、装备选择及两端上下船/行走/再登船；12张真实Scene/PFB检查岸、码头、水深曲线和五个装备格。鱼卡、缩放、字体、图鉴等资源校验保持通过。Windows真实按键脚本已加入背包选线钩回归，本次因测试窗口无法取得系统键盘焦点而未能执行按键阶段；未将该测试记为通过。
