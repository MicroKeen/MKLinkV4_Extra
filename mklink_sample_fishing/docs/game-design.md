# 北方湿地公园：整体设定 v17

2026-10-15。适用 Windows 模拟器与标准 `mklink_sample_fishing`，以下为当前实现，价格和规则覆盖旧版说明。

## 设备与操作

240×240 RGB565，单颗双向旋转、可按下的编码器。旋转移动/调整，短按打开行囊或确认；长按280 ms开始蓄力、1.4 s满蓄力，松开抛竿。漂相进入可提竿窗口后按下，搏鱼时顺转收线、逆转泄力。成功收鱼才揭晓鱼种、尺寸、估算重量、星级和评语。

背包类别顺序为鱼竿、线钩、浮漂、鱼饵、钓深、储鱼容器，随后是上下船、图鉴、存档、返回。底部菜单按屏幕左到右切换，原菜单和装备索引不重排。金币图标及余额显示在标题旁，最大余额1,000,000,000。只选择已拥有的装备与有库存的特殊饵料。

## 地图、背景与场景

水域x=56–904，船中心132–828，左右码头可上下船；13节点虚拟水深0–6m，五分区为芦苇浅湾、开阔水面、泥底深槽、缓流入口、浅岸砾石。左岸步行到x=-120，商店门附近x≤-84短按进入。船与水域碰撞坐标不变，岸上相机可到-144，经过小路/码头世界x=0时连续移动。

原湖景的山、森林、岸、水面保留，夜空在原山林轮廓上方转为接近黑的深蓝，少量星星和圆润月牙随原视差移动；日月被远山和树冠遮挡。生成小路使用同样2像素颗粒，和西岸重叠8像素，码头在上层盖接；外屋也用2倍粗像素。渔具店为柜台近景与放大的老人上半身，保留四种表情和9种情境各两句台词，老人位于柜台后方，原柜台前沿遮挡人物下缘；每次只在桌面左侧展示当前商品，旋转浏览16个稳定条目。

## 鱼种、钓层与活跃时间

保留11种鱼。按落点、水深、钓层、分区、饵料和游戏时间筛选权重；趴地虎、河南华溪蟹仅近岸底层，土鲶仅底层。默认钓到底，行囊可选表层、0.5/1/2/3/4.5/6m。铜/银/金70/25/5为基础比例，实际局部比例随条件变化；卡面稀有度不变，体型星级按物种独立评级。

活跃度是相对出现权重的百分比，100为基础值；这是虚构湿地的游戏数值，不是自然调查结论。5–7点与18–20点按小时线性插值，6点/19点达到晨昏系数，7–18点使用白天系数，20–5点使用夜间系数。午夜连续，非活跃时段仍有机会；不突破水域/钓层/饵料限制。**斑鳜没有夜间偏好：白天和夜间都是100，只在晨昏轻微增加。**

## 等待、夜光漂与搏鱼

基础咬钩轮次由2600改为2860 ms，最多22轮，最久62,920 ms。按线钩隐蔽性和候选鱼重量抽取实际等待，保留原900 ms试饵阶段；一般等待比旧版略长约10%。

夜光漂夜间发明亮蓝绿色光，环境压暗后绘制，附轻微光晕，只显示露出水面的部分；白天维持原色。完全入夜时每轮真实咬钩概率相对提高10%，例如70%→77%，上限100%，晨昏随暗度渐变。这个加成缩短同等条件下的等待，不改变鱼种权重或提竿窗口。

搏鱼仍以20 ms整数步进更新张力、松线、距离、爆发与体力；竿影响抛距/收线，线钩影响强度/距离/窗口/隐蔽性。原有断线、松脱、超距、错失和恢复逻辑保留，不提高稀有鱼默认尺寸。

## 鱼获容器与船尾

初始小木桶10 kg，可升级大木桶20 kg和储鱼箱35 kg。按鱼种汇总数量、重量和估价，容量内恰好装满有效；单条超过当前总容量才挂船尾，限一条。普通鱼没有剩余空间时放流，仍计图鉴；第二条超大鱼放流。升级保留所有鱼获，船尾鱼若可放入新增剩余空间则自动收纳。

鱼获页用压暗容器作背景，鱼图在前景，鱼名/数量/重量/价值放在独立暗色底板，避免纹理干扰。第12页看船尾。大鱼按朝向约30°斜挂，绳索从船尾固定点连接鱼头/鳃部，左右朝向对称。

## 货币与商店

营业时间07:00 AM–06:00 PM（07:00–18:00），外屋正面亮灯/熄灯两种状态表示营业，不再挂牌。尝试进入关门商店时，主角上方显示“打烊了”1.6秒。打烊无人且无法进入或交易，18点退出店内，查看容器后也不能返回已打烊的店；不增加打烊对话。店主台词与表情可在 `docs/merchant-dialogue.md` 修改，装备描述草稿在 `docs/tackle-descriptions.md`。

币重分开：coins为货币，g/kg为重量。单鱼售价为 `max(1, floor((base * size_mm² + typical_mm²/2) / typical_mm²))`，`typical_mm=mean_x2_mm/2`。鱼种基础价仍为白条6、鲫鱼8、鲤鱼12、土鲶12、河南华溪蟹10、马口16、趴地虎16、黑鱼28、黄颡鱼30、中华鳖60、斑鳜72。出售一次结算容器及船尾全部鱼，不清图鉴；超过金币上限整笔拒绝。

## 时间、存档、工程与发布

系统单调毫秒驱动，每1秒现实时间为1分钟游戏时间，一昼夜24分钟，05–07渐亮、18–20渐暗。新游戏起始06:00加运行秒数，读档恢复游戏分钟，退出期间不快进。毫秒余量与uint32回绕安全。

存档v4仍236 B，读取v1/v2/v3。首次升级保持图鉴、金币、饵料库存、鱼获、容器和时间，把竿/线组/漂及所有权恢复为竹竿/通用线钩/红白漂，当前饵料恢复普通假饵，钓深到底。偏移200为容器，201记录装备初始化世代1，202–203保留零；成功写入后，新买的高级装备不再重置。保持原密钥、UUID派生、SD目录和鱼种/装备/饵料索引；迁移写非活动槽、同步并读回校验后确认。旧固件不能读v4，切回本版本可恢复。存档期不操作背光PA26。

标准工程默认 `FISH_LCD_ROTATION=0`，对应ST7789由原2转向180°，240×240窗口按驱动使用Y_SHIFT=80；其他工程未指定时保持默认2。常用Embedded Studio工程在 `hpm5301evklite_flash_uf2_debug/segger_embedded_studio/mklink_sample_fishing.emProject`，选择Debug。方向与帧率仍需实板确认。

公开仓库只保留实际运行链接的 C 位图/蒙版/字形及必需许可；原图、备用版本、PNG/图集、TTF、提示词与预览均留本地。没有新增整屏缓冲。Windows32项CTest、标准demo10项测试、GNU UF2/XIP及SEGGER构建，具体结果见验证报告。尚未实板烧录、掉电或栈水位验证，也未创建Android/微信运行应用。

商店素材统一正面、较平面的构图。外屋44×36逻辑像素加采样边框，2倍显示；门框约28像素，主角26像素。营业亮窗开门，打烊暗窗关门；两个状态共用轮廓，熄灯状态只导出实际变化的门窗区域，避免整屋跳动及重复占用Flash。内景120×72、店主每帧40×50，全部2倍最近邻显示；柜台水平前沿遮挡人物下缘。桌面商品也用2倍整数缩放，鱼竿只转90度，不再混用1.25/1.5/3倍素材。
