# 漂相、距离与搏鱼行为 v5

有效数值及完整调参入口见[数值平衡指南](balance-tuning-guide.md)，鱼饵偏好见[鱼饵设定](bait-design.md)。

试饵/提竿上下界保留，各鱼种漂相、体重拉力和匿名爆发提示保留。上钩不显示鱼种图标。

FAR显示鱼到船的水平距离（m，一位小数），世界标尺25px/m；距离未归零时向上取一位，避免出现0.0m却还没收起。三竿最大水平抛距3.52、4.64、5.60m，靠岸会按实际落点缩短。线组水平放线范围6/8/10m，范围独立于本次抛距。水深仍负责鱼种/钓层筛选，本版未增加三维鱼线形状。

鱼体力只在安全张力下的主动挣扎或有效收线时消耗，静止休息不会持续扣体力。耗尽进入停歇，取消主动爆发、水花和向外拉线；保留轻微水面起伏。停歇1500ms后每200ms回复1点，回复到初始体力20%再恢复正常挣扎。收线距离归零即收鱼，不要求体力先为零。松线/过载/线放尽危险继续存在。

失败后进入1200ms动画：错过提竿漂下沉，断线竿尖回弹，脱钩/过早提竿收回空钩；底部只显示“线断了”“脱钩了”“错过了”等简短结果。结束后恢复操作。完整控制器审计见[验证数据](validation.md)，不作为人类胜率。
