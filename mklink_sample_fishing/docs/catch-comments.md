成功收鱼时，评语替代卡片原来的SEEN行，星级和体型继续保留；每种计数仍记录在状态中。中鱼时不显示评语，避免提前揭晓鱼种。

以下为实装命令，由我执行即可；生成工具会保留这份文件中的修改：

```powershell
python tools/prepare_species.py --data-only
python tools/prepare_remarks.py
.\build.ps1
python tools/verify_species_assets.py
python tools/prepare_previews.py
python tools/memory_report.py
```

prepare_remarks.py只导出评语及图鉴名字需要的12px A1中文字形；源码字库和OFL许可单独保存，不链接整套字体。若新句超出13字，先缩短文字或调整卡片布局。参考字体源版权信息见 assets/fonts/OFL.txt，bitmap字形延续OFL-1.1。
